# AHI App Development — Project Management Artifacts

## Project Overview

This repository contains the core project management deliverables produced during the execution, change control, and closing phases of the **Applied Healthcare Innovations (AHI) App Development Project**. The project delivered a mobile application enabling customers to view skincare product catalogs, check pricing, and process orders securely. The initiative was executed using a hybrid project management approach across three development sprints within a 90-day window.

---

## Repository Deliverables

### 1. Project Status Report (Execution Phase)

* **Contents:**
* **RAG Health Indicators:** Overall and individual health ratings across Scope, Schedule, and Budget.


* **Milestone Progress:** Tracking of key project deliverables and sprint targets.


* **Help Needed:** Prioritized support requests categorized by Must Have, Should Have, and Like to Have with designated owners.


* **Operational Tracking:** Current risks, open project issues, pending sponsor decisions, and team performance recognition.





---

### 2. Change Request Form — CR-0005

* **Contents:**
* **Proposed Change:** Request to ingest two external skincare industry data subscription feeds ($2,500 licensing cost, 2-week lead time).


* **Reason for Change:** Justification covering weekly global sales data and demographic analytics to improve product positioning.


* **13-Point Impact Analysis:** Evaluation covering work products, quality, schedule, scope, budget, resources, other projects, ROI, stakeholders, assumptions, dependencies, risks, and approval thresholds.
* **Implementation Options:** Comparative trade-off analysis of concurrent Sprint 3 integration (Recommended), phased integration, or full deferral to Version 2.
* **Decision & Close-Out:** Multi-stakeholder approval records (Mary Smithers, Cal Hamer, Cary Manning, Priya Service), decision follow-up actions, and completed change close-out checklist.



---

### 3. Project Close-Out Report

* **Contents:**
* **Key Information & Project Goals:** Documentation of the 5 charter project goals and their success ratings (Success, Partial Success, Not Accomplished).
* **Variance Reviews:** Detailed variance explanations and future prevention strategies for **Scope** (omitted feeds/reports), **Schedule** (Sprint 3 recovery), and **Cost** ($7,000 budget overrun).
* **Risk Analysis:** Evaluation of anticipated vs. unanticipated risks impacting the project lifecycle.
* **Outstanding Items:** Action table with assigned owners for UI bug fixes (15 Nov), IT recruitment onboarding (1 Dec), and Version 2 scope migration.
* **Lessons Learned:** Formal documentation of "Did Well" achievements, "Do Better" improvement areas, and PM recommendations.
* **Archives & Sign-Off:** Organizational repository paths (SharePoint, GitLab, Corporate Finance drive) and formal closeout review dates.
